文件索引

按归属域 / 类型 / 温度筛选，分页浏览已索引文件。只读视图。

全文搜索

基于 SQLite FTS5，中文按 2-gram 分词（"报表"可命中"财务报表"）。只读索引，不移动任何文件。

同一文件可属于多个视图，源文件零改动。

清理候选发现

只读发现，绝不删除任何文件。清理动作请生成计划并确认后执行。

低置信度分类与执行失败的项目集中在此。裁决会立即修正当前文件，并把关键词写入反馈供同类文件自动归类；不移动任何文件。

裁决历史

还原与物理清除属于高危操作，仅通过 CLI / MCP 执行并强制二次确认；Web 端只提供只读视图。

容器内已挂载磁盘

来自容器 /proc/mounts 的真实挂载点（仅显示允许根内的目录）。这是物理磁盘在容器里的落点，由 docker-compose 的 volumes 决定。

绑定扫描卷

物理磁盘需先在 docker-compose 里挂载到容器；这里把容器内已可见的目录登记为扫描源。绑定后重新运行「扫描建索引」即可纳入统计。

当前扫描卷

静态卷来自只读配置（解绑=停用标记，不改配置文件）；动态卷由本页面绑定，可彻底移除。

可选能力探测

可选依赖缺失时自动降级，不影响核心流程。绿色=可用，灰色=未启用/未安装。

相似内容（只读）

尚未扫描。

定时任务

cron 调度默认全关，且只跑只读任务（扫描/分类/查重/备份审计）。启用需在 config.yaml 中配置。

操作审计时间线

每次真实文件操作都记录源/目标、SHA-256 与回滚状态，形成可追溯的安全执行证据链。

维护操作

扫描、分类、查重会修改索引，不会动文件本身。

需要先绑定磁盘？到「磁盘挂载」页面登记扫描卷。

危险操作

执行计划会真实移动文件，回滚会撤销最近操作。两者都需二次确认，且全程写操作日志。
