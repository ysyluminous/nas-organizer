# 部署指南

## 1. 前置条件

- 绿联 NAS 已安装 Docker 套件
- 已开启 SMB/共享文件夹访问
- 至少 2GB 可用内存（当前 NAS 内存 15% 使用，充足）

## 2. 目录准备

在 NAS 上创建以下目录（建议放在 volume4 SSD 或 volume5）：

```
/volume4/docker/nas-organizer/
├── config/      # 配置文件
├── data/        # SQLite 数据库
├── logs/        # 日志
└── docker-compose.yml
```

## 3. 配置文件

复制 `config/config.example.yaml` 到 `config/config.yaml`，按实际情况修改：

```yaml
volumes:
  - name: volume1
    path: /nas/8T1
    role: cold
    read_only: true
  - name: volume2
    path: /nas/16t1
    role: cold
    read_only: true
  # ...

write_targets:
  - name: volume5
    path: /write/16t2
    writable: true
```

## 4. Docker Compose

见仓库根目录 `docker-compose.yml`。关键说明：

- **只读挂载**：`/nas/*` 用于扫描，容器无写权限
- **读写挂载**：`/write/*` 仅执行器使用
- **端口**：默认 8765，可按需要修改
- **时区**：Asia/Shanghai

## 5. 构建与启动

```bash
cd /volume4/docker/nas-organizer

# 构建镜像（首次）
docker build -t nas-organizer:latest .

# 启动
docker compose up -d

# 查看日志
docker compose logs -f
```

## 6. 首次使用流程

### 6.1 扫描建索引

```bash
docker exec -it nas-organizer python -m nas_organizer.cli scan
```

首次全量扫描 12 万文件预计 2-5 分钟。之后增量扫描只处理变更文件。

### 6.2 分类与查重

```bash
docker exec -it nas-organizer python -m nas_organizer.cli classify
docker exec -it nas-organizer python -m nas_organizer.cli dedupe
```

### 6.3 生成计划

```bash
docker exec -it nas-organizer python -m nas_organizer.cli plan --domain 生活 --ftype 视频
```

### 6.4 Web 控制台

浏览器访问 `http://NAS_IP:8765`，在控制台中：

1. 查看分类统计和重复文件报告
2. 预览迁移计划
3. 逐条或批量确认
4. 执行并观察日志
5. 如有问题，一键回滚

## 7. 备份策略配置

### 7.1 热数据备份

在 `config.yaml` 中配置：

```yaml
backup:
  hot:
    enabled: true
    source: /write/16t2
    target: /backup/volume5
    schedule: "0 2 * * *"     # 每天凌晨 2 点
    max_age_days: 90
    exclude:
      - "*.tmp"
      - "#recycle/*"
```

### 7.2 冷数据同步

冷数据不搬文件，只做索引校验：

```yaml
backup:
  cold:
    enabled: true
    verify_hash: true
    schedule: "0 3 * * 0"     # 每周日凌晨 3 点
```

## 8. 安全建议

1. **首次运行只做 scan + classify + dedupe，不执行任何 plan**
2. 检查重复报告后，先手动删除确认无误的少数文件，再考虑批量
3. 个人和工作数据务必在 volume5 保留一份副本，或外接硬盘离线备份
4. 启用 NAS 的 btrfs 快照功能，对 `/个人/` 和 `/工作/` 目录做定期快照
5. 执行 plan 前先备份 SQLite 数据库：`cp data/nas_organizer.db data/backup/`

## 9. 常见问题

### Q: 扫描很慢？
A: 首次全量扫描正常。后续增量扫描只处理 mtime 变化的文件。可在配置中限制并发数。

### Q: 分类不准？
A: 检查 `config/domain_rules.yaml` 的关键词，补充你的业务词汇。低置信度文件可在 Web 控制台手动指定。

### Q: 执行失败怎么办？
A: 查看 `plan_items.error` 字段。已执行的操作在 `op_logs` 表中有记录，可用 `rollback` 命令回滚。

### Q: 容器重启后索引还在吗？
A: 在。SQLite 数据库在 `data/` 目录，已映射为持久卷。
