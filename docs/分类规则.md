# 分类规则

分类采用四级判定链，逐级兜底。规则全部可配置，配置文件在 `config/`。

## 1. 判定优先级

```
路径规则 (path_rule) → 扩展名 (ext) → 文件名关键词 (keyword) → 轻量模型 (model)
```

- 前三级命中即停止，后续不再判定
- 每级判定写入 `classified_by` 字段，方便审计
- 模型兜底置信度 < 0.8 的进人工确认队列

## 2. 文件类型规则（config/type_rules.yaml）

按扩展名映射到 8 个类型：

| 类型 | 扩展名 |
|---|---|
| 音乐 | .flac .mp3 .wav .m4a .aac .ogg .ape .wma |
| 视频 | .mp4 .mkv .avi .mov .rmvb .wmv .flv .webm .m4v .ts |
| 图书 | .pdf .epub .mobi .azw3 .djvu .txt .doc .docx（书籍语义）|
| 文档 | .doc .docx .xls .xlsx .ppt .pptx .csv .txt .md .pdf（非书籍）|
| 图片 | .jpg .jpeg .png .gif .bmp .webp .heic .tiff .svg |
| 软件 | .exe .msi .apk .dmg .deb .rpm .appimage .zip（安装包语义）|
| 压缩包 | .zip .rar .7z .tar .gz .bz2 .xz |
| 其他 | 未命中以上任何规则 |

**注意**：同一个扩展名可能属于不同类型（如 `.pdf` 既是图书也是文档）。优先级：
1. 路径规则先判定（如 `/电子书/` 下的 `.pdf` → 图书）
2. 文件名关键词再判定（如含"报告/合同" → 文档）
3. 默认按扩展名兜底

## 3. 归属域规则（config/domain_rules.yaml）

### 工作

关键词：`合同 报表 项目 方案 报告 会议 客户 财务 审计 招标 发票 工资 考勤 周报 总结 规划 架构 接口 API 代码 src config deploy`

路径特征：`/工作/`、`/项目/`、`/5公司文件/`、`/到家/`、`/yh/`

### 生活

路径特征：`/生活/`、`/Photos/`、`/相册/`、`/照片/`、`/做饭/`

### 个人

关键词：`证件 身份证 护照 学历 证书 简历 银行卡 密码 账号 笔记 日记`

## 4. 温度规则（config/temperature_rules.yaml）

```yaml
hot:
  max_age_days: 90          # 90 天内访问过
  volume_hint: hot          # config.yaml 中 role=hot 的卷一律视为热
warm:
  max_age_days: 365         # 一年内访问过
cold:
  default: true             # 其余一律冷
  force_if_size_gt_gb: 2    # 大于 2GB 且超过 1 年未访问
```

判定顺序：先看卷（SSD → 热），再看时间，再看大小。

## 5. 模型兜底

### 5.1 训练数据

从已有数据中采样：每种归属域取 500-1000 个已确认样本，用路径+文件名作为文本。

### 5.2 模型选择

- **首选**：fastText（模型 < 5MB，CPU 推理毫秒级，支持多标签）
- **备选**：TF-IDF + 逻辑回归（sklearn，模型 < 2MB）

### 5.3 置信度阈值

```yaml
model:
  threshold: 0.8            # 低于此值进人工队列
  min_training_samples: 500
  retrain_interval_days: 30
```

## 6. 冲突处理

迁移时如目标路径已存在同名文件：

| 策略 | 说明 |
|---|---|
| `rename` | 加时间戳后缀 `文件名_20261111_201530.ext`（默认）|
| `skip` | 跳过，记录到计划明细 status=skipped |
| `replace` | 覆盖（需用户显式授权，默认禁用）|

## 7. 目标路径模板

```
/{write_target}/{domain}/{ftype}/{temp}/{filename}
```

其中 `write_target` 是 `config.yaml` 中 `write_targets[].path` 配置的容器内路径，与实际 NAS 品牌无关。

示例：
```
/write/target/生活/视频/温/电影-2016.mp4
/write/target/个人/文档/热/证件扫描.pdf
/write/target/资源/图书/冷/电子书合集.pdf
```
