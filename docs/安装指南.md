# 安装指南（总览）

NAS Organizer 是**通用 Docker 应用**，不绑定任何 NAS 品牌。只要你的设备能运行 Docker 且是 x86-64 / ARM64 架构，就能安装。

## 一、支持的平台

| 平台 | 专属文档 | 说明 |
|---|---|---|
| 群晖 Synology (DSM 7 / 6) | [群晖.md](安装/群晖.md) | Container Manager / Docker 套件 |
| 威联通 QNAP (QTS / QuTS hero) | [威联通.md](安装/威联通.md) | Container Station |
| 铁威马 TerraMaster (TOS) | [铁威马.md](安装/铁威马.md) | Docker 管理器 |
| 飞牛 fnOS | [飞牛.md](安装/飞牛.md) | 内置 Docker 管理 |
| 绿联 UGREEN NAS (UGOS Pro) | [绿联.md](安装/绿联.md) | 内置 Docker 管理 |
| 其他 Linux / 通用 x86 主机 | [通用Docker.md](安装/通用Docker.md) | Debian/Ubuntu/CentOS/迷你主机 |
| Windows / macOS 开发机 | [通用Docker.md](安装/通用Docker.md) | Docker Desktop |

架构要求：x86-64（amd64）或 ARM64。镜像基于 `python:3.11-slim`，两种架构都有官方支持。

## 二、所有平台通用的四步

无论什么品牌，流程都一样，只是"路径"和"点哪里"不同：

### 第 1 步：准备项目目录

在 NAS 上建一个专门目录，例如：

```
/你的存储池/docker/nas-organizer/
├── docker-compose.yml     ← 从仓库根目录复制
├── .env                   ← 从 .env.example 复制并修改
├── config/                ← 从仓库 config/ 复制整个目录
│   ├── config.yaml        ← 从 config.example.yaml 复制
│   ├── type_rules.yaml
│   ├── domain_rules.yaml
│   └── temperature_rules.yaml
├── data/                  ← 空目录，应用自动创建数据库
└── logs/                  ← 空目录
```

把仓库代码上传到该目录（`git clone` 或打包上传均可）。

### 第 2 步：改两个文件

1. **`.env`** —— 填你的宿主机路径和 UID/GID（见 [挂载配置指南](挂载配置指南.md)）
2. **`config/config.yaml`** —— 填对应的容器内扫描路径

### 第 3 步：启动

```bash
cd /你的存储池/docker/nas-organizer
docker compose up -d --build
docker logs -f nas-organizer
```

首次启动日志会打印**随机管理员密码**，记下来。

### 第 4 步：登录并体检

浏览器打开 `http://NAS的IP:8765`（若 `.env` 中 `LISTEN_IP=127.0.0.1`，需通过 SSH 隧道或改成 NAS 内网 IP）。

登录后按顺序：

1. 「操作」页 → 扫描建索引
2. 「操作」页 → 重新分类
3. 「操作」页 → 重复检测
4. 「概览」页看统计，判断分类规则是否需要调整
5. 「迁移计划」→ 生成计划 → 查看明细 → 确认无误后再执行

> 前四步全部只读，不会改动你的任何文件。只有点击"执行"才会真正移动文件。

## 三、开始之前必须理解的三件事

1. **路径不通用**：`/volume1/xxx` 是群晖/绿联的路径，威联通是 `/share/xxx`，飞牛是 `/vol1/1000/xxx`。照抄别的教程会扫到空目录。用 SSH 执行 `df -h` 确认自己的真实路径。
2. **权限靠 UID/GID**：容器内用户必须对共享文件夹有读权限。用 `id 用户名` 查 UID/GID 填进 `.env`。详见 [挂载配置指南](挂载配置指南.md) 第四节。
3. **不要暴露公网**：默认端口只绑 `127.0.0.1`。需要远程访问请用 VPN 或反向代理 + HTTPS，详见 [安全与认证](安全与认证.md)。

## 四、没有 SSH 怎么办？

多数品牌的文件管理器可以直接创建文件夹、上传文件、编辑文本。Docker 图形界面也能设置卷映射和环境变量。可以全程不用命令行，但：

- 查 UID/GID 强烈建议开 SSH（ DSM / QTS / TOS / fnOS / UGOS Pro 都在控制面板里有"启用 SSH"开关）
- 图形界面设置卷映射时，务必确认挂载为**只读（RO）**，写入目录才用**读写（RW）**
- 环境变量至少设置 `PUID`、`PGID`、`TZ`，否则权限会出问题

## 五、验证安装成功

```bash
docker ps | grep nas-organizer
docker exec nas-organizer id                    # 确认不是 uid=0(root)
docker exec nas-organizer ls /scan/media1 | head  # 确认能看到你的文件
curl http://127.0.0.1:8765/api/auth/status      # 应返回 {"auth_required":true,...}
```

如果 `ls /scan/media1` 为空但不是权限错误，检查 `.env` 路径是否指向了正确的共享文件夹。

## 六、卸载

```bash
docker compose down
```

`data/`、`config/`、`logs/` 保留在宿主机，不会删除。确认不再需要后再手动删除目录。
