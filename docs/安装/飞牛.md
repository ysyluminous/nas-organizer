# 飞牛 fnOS 安装指南

适用：飞牛私有云 fnOS（x86-64 机型），使用内置的 Docker 管理功能。

## 1. 前置准备

1. 系统设置 → **SSH 服务** → 开启 SSH（用于查 UID 和排错）
2. 应用中心安装或启用 **Docker**（部分版本已内置）
3. 在文件管理中创建用于存放项目文件的文件夹，例如 `docker`

## 2. 确认路径与 UID/GID

```bash
df -h | grep vol
ls -ld /vol1/* /vol1/1000/* 2>/dev/null

id 你的用户名
# 例：uid=1000( fnosuser ) gid=100(users)
```

飞牛常见路径：

- 用户家目录：`/vol1/1000/文件夹名`
- 共享文件夹：`/vol1/文件夹名`（具体以 `df -h` 为准）

多块硬盘时可能是 `/vol2`、`/vol3`。

## 3. 创建项目目录

```bash
mkdir -p /vol1/1000/docker/nas-organizer/{config,data,logs}
cd /vol1/1000/docker/nas-organizer

git clone https://github.com/ysyluminous/nas-organizer.git .
cp .env.example .env
cp config/config.example.yaml config/config.yaml
```

编辑 `.env`：

```env
LISTEN_IP=192.168.1.103
WEB_PORT=8765
PUID=1000
PGID=100
SCAN_1=/vol1/1000/Media
WRITE_TARGET=/vol1/1000/docker/nas-organizer-target
```

编辑 `config/config.yaml`：`volumes[].path` 填 `/scan/media1`，`write_targets[].path` 填 `/write/target`。

授权：

```bash
chown -R 1000:100 /vol1/1000/docker/nas-organizer
```

## 4. 启动

**方式 A：SSH（推荐）**

```bash
cd /vol1/1000/docker/nas-organizer
docker compose up -d --build
docker logs -f nas-organizer
```

若系统只提供 `docker-compose` 命令，替换即可。

**方式 B：Docker 图形界面**

1. 打开 Docker 管理 → **项目 / Compose**
2. 新建项目，项目路径选 `/vol1/1000/docker/nas-organizer`
3. 上传或粘贴 `docker-compose.yml`，确认卷映射后部署

## 5. 首次登录

从容器日志获取随机密码，浏览器访问 `http://飞牛NAS的IP:8765`，登录后立即改密。

## 6. 飞牛专属注意事项

- 飞牛的用户目录含 UID 数字（如 `/vol1/1000/`），换账号后路径会变，请以 `df -h` 实际输出为准
- 图形界面添加卷映射时，注意区分"只读"和"读写"，扫描源务必选只读
- 若把项目放在外置存储或休眠硬盘上，容器可能随硬盘休眠而卡顿，建议放在常驻卷
- 飞牛更新系统后 Docker 数据目录可能被重置，更新后请检查容器是否仍正常启动

## 7. 常见问题

| 现象 | 解决 |
|---|---|
| 扫描路径为空 | 确认 `/vol1/1000/...` 中的数字与当前用户 UID 一致 |
| 容器无法启动 | `docker logs nas-organizer`；检查 `.env` 路径是否存在 |
| 权限问题 | `id` 核对 UID/GID；确认该用户对媒体文件夹有读权限 |
| 更新系统后容器消失 | 检查 Docker 数据与项目目录，重新 `docker compose up -d` |
