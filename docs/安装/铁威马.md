# 铁威马 TerraMaster 安装指南

适用：TOS 4.x / 5.x，支持 x86 机型（部分 ARM 机型请先在应用中心确认 Docker 可用性）。

## 1. 前置准备

1. TOS 控制面板 → **终端与 SSH** → 启用 SSH
2. 应用中心安装 **Docker 管理器**（部分版本名称可能为 Docker / Container Station）
3. 在存储管理中创建用于存放项目文件的共享文件夹，例如 `docker`

## 2. 确认路径与 UID/GID

```bash
df -h | grep -i volume
ls -ld /Volume1/*

id 你的用户名
# 例：uid=1000(admin) gid=100(users)
```

铁威马路径**注意大小写**：常见为 `/Volume1/文件夹名`（大写 V），请以 `df -h` 实际输出为准。

## 3. 创建项目目录

```bash
mkdir -p /Volume1/docker/nas-organizer/{config,data,logs}
cd /Volume1/docker/nas-organizer

git clone https://github.com/ysyluminous/nas-organizer.git .
cp .env.example .env
cp config/config.example.yaml config/config.yaml
```

编辑 `.env`：

```env
LISTEN_IP=192.168.1.102
WEB_PORT=8765
PUID=1000
PGID=100
SCAN_1=/Volume1/共享文件夹
WRITE_TARGET=/Volume1/docker/nas-organizer-target
```

编辑 `config/config.yaml`：`volumes[].path` 填 `/scan/media1`，`write_targets[].path` 填 `/write/target`。

授权：

```bash
chown -R 1000:100 /Volume1/docker/nas-organizer
```

## 4. 启动

**方式 A：SSH（推荐）**

```bash
cd /Volume1/docker/nas-organizer
docker compose up -d --build
docker logs -f nas-organizer
```

旧版 TOS 的 Docker 可能只支持 `docker-compose` 命令，按实际提示调整。

**方式 B：Docker 管理器图形界面**

1. 打开 Docker 管理器 → **项目 / Compose**
2. 新建项目，选择项目目录 `/Volume1/docker/nas-organizer`
3. 读取 `docker-compose.yml`，确认后部署

## 5. 首次登录

查看容器日志获取随机密码，浏览器访问 `http://NAS的IP:8765`，登录后立即在「安全设置」改密。

## 6. 铁威马专属注意事项

- **路径大小写敏感**：`/Volume1` 与 `/volume1` 是两个不同路径，写错会挂载空目录
- TOS 部分版本的内置 Docker 对 compose 的 `build` 字段支持不完整；若图形界面构建失败，改用 SSH 命令行
- 若应用中心没有 Docker，请确认机型与 TOS 版本是否支持；不支持时可考虑在局域网内另找一台 x86 主机运行，把 NAS 共享文件夹用 NFS/CIFS 挂载过去（见 [通用Docker.md](通用Docker.md)）
- 建议对重要数据目录启用 TOS 的快照或 USB 备份

## 7. 常见问题

| 现象 | 解决 |
|---|---|
| 挂载后目录是空的 | 检查 `/Volume1` 大小写，用 `ls` 确认路径下确实有文件 |
| 容器起不来 | `docker logs nas-organizer` 查看；常见为路径不存在 |
| 权限不足 | `id` 查 UID/GID，确认 TOS 中该用户对共享文件夹有读权限 |
| 找不到 Docker 应用 | 机型/系统版本不支持，改用外部主机方案 |
