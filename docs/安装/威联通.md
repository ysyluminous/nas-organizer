# 威联通 QNAP 安装指南

适用：QTS 5.x / QuTS hero h5.x，支持 x86 与 ARM 机型。

## 1. 前置准备

1. QTS 控制台 → **网络和文件服务** → **Telnet/SSH** → 勾选 **允许 SSH 连接**
2. App Center 安装 **Container Station**（容器工作站）
3. SSH 登录 NAS

## 2. 确认路径与 UID/GID

```bash
df -h | grep share
ls -ld /share/*

id 你的用户名
# 例：uid=1000(admin) gid=100(users) → PUID=1000 PGID=100
```

威联通共享文件夹通常在 `/share/文件夹名`（注意 `share` 后没有 `s`）。

Container Station 自身的数据目录通常是 `/share/Container` 或 `/share/Public/Container`，项目文件放这里很合适。

## 3. 创建项目目录

```bash
mkdir -p /share/Container/nas-organizer/{config,data,logs}
cd /share/Container/nas-organizer

git clone https://github.com/ysyluminous/nas-organizer.git .
cp .env.example .env
cp config/config.example.yaml config/config.yaml
```

编辑 `.env`：

```env
LISTEN_IP=192.168.1.101
WEB_PORT=8765
PUID=1000
PGID=100
SCAN_1="/share/Multimedia"         # 路径含空格必须加引号
WRITE_TARGET=/share/Container/nas-organizer-target
```

编辑 `config/config.yaml`，把 `volumes[].path` 改为 `/scan/media1`，`write_targets[].path` 改为 `/write/target`。

授权应用目录：

```bash
chown -R 1000:100 /share/Container/nas-organizer
```

## 4. 启动

**方式 A：SSH（推荐）**

```bash
cd /share/Container/nas-organizer
docker compose up -d --build
docker logs -f nas-organizer
```

QTS 自带 Docker 版本较老时，先升级 Container Station 到最新版；若仍不支持 `docker compose` 插件，用 `docker-compose`（旧命令）。

**方式 B：Container Station 图形界面**

1. 打开 Container Station → **应用程序** → **创建**
2. 粘贴或上传 `docker-compose.yml` 内容
3. 按提示创建，等待启动

图形界面创建时，请逐项确认卷映射的 **RO/RW** 与 compose 文件一致：扫描源 RO，写入目标 RW。

## 5. 首次登录

`docker logs nas-organizer` 中查看随机密码，浏览器访问 `http://NAS的IP:8765` 登录后立即改密。

## 6. 威联通专属注意事项

- 路径中的空格必须处理：`.env` 中用引号包裹整个赋值，compose 中保持 `"${SCAN_1}:/scan/media1:ro"` 的双引号
- QuTS hero 使用 ZFS，建议对存放重要数据的共享文件夹启用**快照**
- QTS 的 Docker 容器默认网络为 bridge，`LISTEN_IP` 写 NAS 的 LAN IP 即可
- 若 App Center 找不到 Container Station，请确认 NAS 型号支持 Docker（部分低配 ARM 机型不支持）
- 威联通用户 UID 通常从 1000 起，但请务必以 `id` 命令为准

## 7. 常见问题

| 现象 | 解决 |
|---|---|
| Container Station 启动容器失败 | 先看 SSH 下 `docker logs nas-organizer` 的具体报错 |
| 路径含空格导致挂载失败 | `.env` 加引号；避免用含空格的共享文件夹名 |
| 扫描不到文件 | 确认 `config.yaml` 用容器内路径 `/scan/media1` |
| 权限不足 | `id` 核对 UID/GID；在 QTS 中给该用户共享文件夹读权限 |
| 容器端口访问不到 | 确认 `LISTEN_IP` 不是 `127.0.0.1`；检查 QTS 防火墙设置 |
