# 绿联 UGREEN NAS 安装指南

适用：UGOS Pro（绿联 NAS 系统），内置 Docker 管理，支持 x86 机型。

## 1. 前置准备

1. 控制面板 → **终端 / SSH** → 启用 SSH
2. 打开系统内置的 **Docker** 应用，确认可用
3. 在存储管理中创建用于存放项目文件的共享文件夹，例如 `docker`

## 2. 确认路径与 UID/GID

```bash
df -h | grep volume
ls -ld /volume*

id 你的用户名
# 记下 uid= 和 gid= 后的数字
```

绿联共享文件夹常见路径为 `/volume1/...` 到 `/volume5/...`，具体取决于你的存储池和卷编号。

> 本项目的作者案例使用 `/volume1/8T1` ~ `/volume5/16t2`，那只是个人环境，**不代表你的路径**。请务必用 `df -h` 确认自己的实际路径。真实案例数据已单独整理在 [案例：绿联 NAS 现状诊断](../案例-绿联NAS现状诊断.md)。

## 3. 创建项目目录

```bash
mkdir -p /volume1/docker/nas-organizer/{config,data,logs}
cd /volume1/docker/nas-organizer

git clone https://github.com/ysyluminous/nas-organizer.git .
cp .env.example .env
cp config/config.example.yaml config/config.yaml
```

编辑 `.env`（示例，路径请替换成你的）：

```env
LISTEN_IP=192.168.1.104
WEB_PORT=8765
PUID=1000
PGID=100
SCAN_1=/volume5/16t2          # 改成你的共享文件夹
SCAN_2=/volume2/16t1          # 需要多个盘再加，并在 compose 中取消对应行注释
WRITE_TARGET=/volume1/docker/nas-organizer-target
```

编辑 `config/config.yaml`：

```yaml
volumes:
  - name: media1
    path: /scan/media1        # 容器内路径
    role: warm
  - name: archive1
    path: /scan/media2
    role: cold
write_targets:
  - name: target
    path: /write/target
    writable: true
```

授权：

```bash
chown -R 1000:100 /volume1/docker/nas-organizer
```

## 4. 启动

**方式 A：SSH（推荐）**

```bash
cd /volume1/docker/nas-organizer
docker compose up -d --build
docker logs -f nas-organizer
```

**方式 B：Docker 图形界面**

1. 打开 Docker 应用 → **项目 / Compose**
2. 新建项目，路径选择 `/volume1/docker/nas-organizer`
3. 读取 `docker-compose.yml`，确认卷映射后启动

若图形界面不支持从 compose 构建，先用 SSH 命令构建镜像，再在界面中创建容器。

## 5. 首次登录

容器日志会打印随机管理员密码：

```bash
docker logs nas-organizer 2>&1 | grep '随机管理员密码'
```

浏览器访问 `http://绿联NAS的IP:8765`，登录后立即到「安全设置」修改密码。

## 6. 绿联专属注意事项

- UGOS Pro 的共享文件夹路径含卷编号（`/volumeN/`），多盘环境下编号不直观，务必用 `df -h` 核对
- 内置 Docker 界面的卷映射可能通过"选择文件夹"完成，选择后请确认是**只读**（扫描源）还是**读写**（写入目标）
- 绿联 Docker 应用升级后容器一般会自动恢复，但建议升级后执行 `docker ps` 确认状态
- 作者环境中的存储池均为 basic 单盘无 RAID，因此项目默认全程 dry-run；强烈建议你也保持这个习惯，并对重要目录做外部备份

## 7. 常见问题

| 现象 | 解决 |
|---|---|
| 路径写法和教程不一样 | 正常，每个人卷编号不同，以 `df -h` 为准 |
| 容器访问不到 | 检查 `LISTEN_IP` 是否设为 NAS 内网 IP；确认绿联防火墙未拦截 8765 |
| 扫描 0 文件 | `config.yaml` 里必须是 `/scan/media1` 这类容器内路径 |
| 权限不足 | 用 `id` 查正确 UID/GID 更新 `.env`，并确认账号对共享文件夹有读权限 |
