# 下载目录体检

## 调用链（当前全部只读）

1. `search_files(keyword=.part|.part1|.!ut|.torrent)` — 未完成下载与种子
2. `search_files(keyword=.exe|.msi|.dmg|.apk)` — 安装包
3. `search_files(keyword=.zip|.rar|.7z)` — 压缩包
4. `find_old_files(days=180, limit=50)` — 陈年文件
5. `find_large_files(min_bytes=2147483648)` — 超大文件
6. 汇总成**待确认清单**：路径 / 大小 / 最后修改 / 判定理由

## 输出原则

清单必须分组呈现，每组标注"建议动作"：

| 分组 | 建议 |
|---|---|
| 未完成下载 / 种子 | 可清理（用户确认后） |
| 安装包 | 核对是否仍需安装后再定 |
| 陈年压缩包 | 先查重，已有副本才清理 |
| 正在使用的文件 | 不动 |

## 边界

- **默认不生成删除计划**；只有用户明确要求"生成清理计划"时才 `plan_create`
- 不物理删除；走计划 → 确认 → 回收站
- 不扫描系统回收站目录（`#recycle`）
- 下载目录路径必须由用户指定且在白名单内，不猜测
