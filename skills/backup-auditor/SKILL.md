# 备份与数据健康审计

本 Skill 只读，产出审计报告，不直接改备份配置。

## 调用链

1. `get_stats_by_temperature` — 冷热分布；热数据占比过高说明归档不足
2. `backup_verify` — 冷数据是否缺失或大小变化
3. `count_files(domain=个人|工作, temp=热)` — 不可再生数据的活跃量
4. `list_op_logs(limit=50)` — 近期文件变更与回滚状态
5. `list_scan_states` — 索引是否陈旧（决定报告可信度）
6. `get_duplicate_summary` — 重复占用，判断是否需要释放空间

## 审计报告结构

```
冷数据校验：总数 N / 缺失 X / 大小变化 Y
关键数据：个人+工作 热数据 N 条，是否有离线副本（需用户确认）
近期变更：op_logs 最近 N 条，其中已回滚 X 条
风险提示：
  - 单盘 basic 池无 RAID，任何一块故障数据全丢（需提醒）
  - 索引超过 7 天未更新，报告可能失真
建议：先跑 nas-report 路由，或 dedup-finder 释放空间
```

## 边界

- 不读取 `data/auth.yaml` 与密钥文件
- 不自动创建备份副本；`backup_hot` 必须另经用户确认
- 不物理删除任何文件
- 明确告知：本工具不替代 RAID / 快照 / 异地备份
